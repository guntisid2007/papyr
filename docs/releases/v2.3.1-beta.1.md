# Papyr 2.3.1-beta.1 (draft, not published)

This is the first beta of Papyr 2.3.1. It is for testing only. Please keep copies of anything you convert until
you have checked the results.

## Who should try it

People with a **Mac with Apple silicon** (M1 or later) running macOS 14.4 or later. This is the only build offered
for this beta. See [What was tested](#what-was-tested) for the other systems.

## What changed since 2.3.1

- **No partial results.** If a file fails or you cancel part way, none of that file's pages are left behind, and the
  rest of the batch still converts.
- **Existing files are never replaced.** That includes files another program creates at the same moment, and files
  on exFAT and FAT32 drives. New files get a ` (1)` suffix instead. The one exception is a merged file you agree to
  replace.
- **Animations stay animated.** Animated GIF and WebP keep their frames, timing, looping, and transparency when
  converted to WebP or to an animated GIF. Other formats and PDF take the first frame, or every frame with the
  **Every frame** switch.
- **Protected PDFs keep their protection.** Papyr no longer copies an encrypted PDF into a new PDF. That copy
  dropped the owner's restrictions for RC4-encrypted files. An encrypted PDF becomes images only when its owner
  allows copying its content.
- **Converted files can be read by other accounts.** 2.3.1 saved them so that only your account could read them.
  They now get the same permissions as files any other app saves.
- Fixed: quitting during a conversion crashed Papyr. Also fixed: a late thumbnail after closing the window, long
  file names, misleading error messages, and several smaller window problems.

## Install on a Mac with Apple silicon

1. Download `Papyr-2.3.1-beta.1-macOS-AppleSilicon.zip` and its `.sha256` file.
2. Check the download. In Terminal, in the download folder, run:

   ```sh
   shasum -a 256 -c Papyr-2.3.1-beta.1-macOS-AppleSilicon.zip.sha256
   ```

   It must print `OK`.
3. Double-click the ZIP. Drag **Papyr.app** into **Applications**.
4. Open Papyr. macOS warns that it can't verify the app. **This build is not signed with an Apple Developer ID and
   is not notarized by Apple.** To open this one app:
   - Click **Done** on the warning.
   - Open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to the message
     about Papyr.
   - Confirm with your password or Touch ID, then click **Open**.

   This approves Papyr only. Don't turn off Gatekeeper or other macOS protections to run it.

If you also have an older Papyr, quit it first. Both use the same settings.

## Known limitations

- Not signed with a Developer ID and not notarized (see above). Windows and Linux builds are not part of this beta.
- A PDF that needs a password to open is refused. An encrypted PDF is never copied into a new PDF. It becomes
  images only if its owner allows copying.
- Animated PNG and multi-image HEIC files convert their first image only.
- Animated WebP output holds every frame in memory, so animations over about 134 million pixels in total are
  refused. libwebp merges a frame identical to the one before it. Playback and total time stay the same.
- On disks without an atomic no-replace move (for example exFAT on macOS), Papyr writes each finished file by
  copying it into a newly created name. If the Mac loses power during that copy, a partly written file can remain.
  After any crash, a hidden `.papyr-….part` file can also remain in the destination folder. It is safe to delete.
- No limit on PDF page count. A 10,000-page PDF becomes 10,000 images. Cancel works between pages.
- A 12-page PDF converted to JPEG gives 12 JPEG files, one per page. JPEG holds one picture. Choose GIF for one
  animated file, or PDF for one document.
- Three small window issues remain:
  - **Edit → Remove Selected** is greyed out while the Edit menu is open. Delete and Backspace still work.
  - Thumbnails of removed files stay in memory until Papyr quits.
  - A duplicate dropped together with a new file is skipped without a notice.

## What was tested

Full evidence is in `tests/reports/beta-release-readiness.md`. In short:

- **macOS Apple silicon (this beta's build):**
  - 1,261 tests passed, with none failed or skipped, on a Mac mini (macOS 26.6.2) and on a GitHub Actions runner
    (macOS 15).
  - All 110 supported conversion pairs passed, 500 of 500 conversions, each checked independently of the converter.
  - The packaged app passes its self-test before and after the ZIP is unpacked.
  - It launched through Finder's open-document path with a PNG and a 12-page PDF.
  - **Not yet done by a person:** native file dialogs, Finder drag and drop, the Dock, Cancel, and Quit during a
    conversion. Beta testers can follow `tests/reports/native-macos-checklist.md`.
- **macOS Intel, Windows, and Linux:** the same tests and matrix pass on GitHub Actions runners, and each
  platform's package passes its self-test there. No person has used these builds, so they are not offered in this
  beta.

## Beta testing

Please try your own files, especially:

- HEIC photos from your phone.
- Multi-page PDFs, including statements or forms that may be protected.
- Animated GIFs.
- Jupyter notebooks.
- Large batches.

## Reporting a bug

Open an issue at <https://github.com/guntisid2007/papyr/issues> and include:

1. Your Mac model, macOS version, and "2.3.1-beta.1". The About box shows 2.3.1 for this beta.
2. The steps you took. Include the output format and its options.
3. What you expected and what happened. Include the exact sentence Papyr showed, if any.
4. The log file `~/Library/Logs/Papyr/papyr.log`. It holds file paths and error messages, never file contents.
   Remove any path you'd rather not share.
5. If you can, a sample file that fails. Attach only files you're comfortable making public. Otherwise describe
   the file: format, size, pages, and where it came from.

To reproduce a conversion failure from source, see "Reproduce a conversion failure" in `tests/README.md`.
